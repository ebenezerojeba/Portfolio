PalmsBeauty

An appointment booking platform for a beauty salon in St. John's, Newfoundland, with an admin panel for managing bookings.

The live demo is currently offline.

Overview

PalmsBeauty is a full-stack appointment booking platform for a beauty salon in St. John's, Newfoundland and Labrador, Canada. Clients book beauty services online, and the salon manages appointments and day-to-day operations from an admin panel.

The problem it solves

Taking bookings by phone and direct message makes it easy to double-book or lose track of appointments. PalmsBeauty gives clients self-service booking and gives the salon one dashboard for every appointment.

My contribution

Full-stack development of the booking site, admin panel and backend API.

Key features

  • Online appointment booking for beauty services.
  • Admin panel with an overview of completed, cancelled and total appointments, and a list of the latest bookings to confirm or cancel.
  • Secure authentication for clients and administrators.
  • Automated notifications to confirm appointments.
  • Responsive design for mobile and desktop.

Architecture overview

  • MERN stack: React frontend and admin panel with Tailwind CSS and Framer Motion, and a Node.js / Express API with MongoDB.
  • Separate client-facing site and admin interface sharing one backend.

Technology stack

  • MongoDB
  • Express
  • React
  • Node.js
  • Tailwind CSS
  • Framer Motion
